# harness-improvement

Start from concrete evidence. State the user outcome, cost, risk, and smallest
experiment.

- Do not auto-implement speculative improvements.
- Record an actionable proposal in root `kaizen.md` or obtain explicit approval.
- Promote only verified, reusable outcomes to `MEMORY.md`.
- Keep a rejected experiment as evidence, not as a hidden rule.

Follow `.codex/skills/harness-learning/references/knowledge-contract.md` and
the evidence gates in `.codex/skills/harness-delivery/references/delivery-contract.md`.
