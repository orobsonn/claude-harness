# harness-learning

Record only concise, evidence-backed, non-secret learnings in the root
`MEMORY.md` index. Put a proposed next improvement in root `kaizen.md`.

- Separate observations from hypotheses and preserve source paths and verification.
- Do not turn transient session state into durable instructions.
- Never overwrite an operator's entry or store secret/PII material.
- Adapt imported runtime knowledge to actual Codex capabilities before keeping it.

Apply `.codex/skills/harness-learning/references/knowledge-contract.md` and
the verification bar in `.codex/skills/harness-delivery/references/delivery-contract.md`.
